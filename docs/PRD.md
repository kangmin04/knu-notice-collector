# PRD: 자동수집 대상 확장 (경북대 9곳 → 대구/전국 포함 27곳 내외)

## 배경 / 문제 정의

`공지사항-모음`은 경북대 컴퓨터학부 학생이 공모전·해커톤·프로젝트·일경험·교환학생·진로취업 정보를 여러 사이트를 매번 돌아다니며 확인하는 불편을 줄이기 위한 자동 수집기다.

노션 "정보 소스 모음" DB에는 경북대 공식 채널 12곳, 대구 지역 채널 8곳, 전국 플랫폼 16곳 등 총 36곳이 조사되어 있지만, 실제 자동 수집기(`src/sites.js`)에는 **정적 HTML 정규식 파싱이 검증된 경북대 게시판 9곳만** 등록되어 있었다. 나머지 27곳은 노션 DB에만 남아 있고 사용자가 수동으로 확인해야 했다.

## 목표

자동수집 대상을 9곳에서 **27곳 내외**로 확장한다. 정적 HTML로 파싱 가능한 사이트는 cheerio 기반 파서로, 클라이언트 렌더링(SPA)이라 정적 파싱이 불가능한 사이트는 Playwright 헤드리스 브라우저로 렌더링 후 동일한 파서 계층을 재사용해 수집한다.

이 4곳은 이번 확장 범위에서 제외하고 `src/sites.js` 상단 주석과 노션 "정보 소스" DB에만 남긴다. 추후 더 깊은 조사(브라우저 개발자도구 Network 탭 직접 관찰, 또는 Playwright로 실제 AJAX 요청을 가로채는 방식)로 재시도할 수 있다.

## 성공 기준

- 신규 사이트 추가 시 기존 게시글이 스팸으로 노션에 쏟아지지 않는다 (사이트별 최초실행 안전장치 선행 적용).
- 각 신규 파서가 최소 1회 이상 실제 사이트에서 파싱된 제목/링크를 사람이 검증했다.
- GitHub Actions 매일 09:00 KST 실행이 Playwright 도입 후에도 안정적으로 완료된다.
- 사이트 하나의 수집 실패가 전체 실행을 막지 않는다 (기존 try/catch 격리 유지).

## 비목표

- 로그인이 필요한 사이트(KNUCUBE 등) 수집.
- Cloudflare 등 봇 차단을 능동적으로 우회하는 기법 적용.
- 실시간/폴링 방식 수집 — 하루 1회 배치 유지.
- 전체 36개 노션 DB 사이트를 예외 없이 자동화하는 것 — 기술적으로 불가능하거나 실익이 없는 곳은 명시적으로 제외한다.
